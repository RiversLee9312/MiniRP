# 智能体搜索

## 智能体搜索是什么

开启后，聊天角色需要查东西时，会把查询交给一个专门负责查资料的智能体。它可以查真实网页，也会按预设的设定整理已经确认的资料和世界里能找到的信息，再把结果交给角色。例如你在一座虚构港口查停航时间，角色拿到的是它能搜到的通告，用户不必跟着查看每一步。群像里，每个角色有自己的搜索会话。

关闭后，聊天角色自己决定怎么搜、怎么看网页、怎么核对资料。少一道分工，角色也会直接承担研究和设定的一致性。两个选项都能查网页，开关决定的是谁负责查和整理。具体能否访问网页还取决于网络和已配置的搜索或抓取服务。

如果你希望角色维持视角、世界资料逐步浮现，或者研究流程比较复杂，可以开。如果你希望一个主持人直接处理规则查询，或者对话不太需要搜东西，可以关。PresetAgent 应先问你的偏好，再写配置。

### 配置分工

- `chat_agent.system_prompt` 写角色或主持人的行为、表达方式、可以做的决定和与玩家的边界。
- `search_agent.system_prompt` 写证据的范围、可信度和呈现方式。单角色强调它能接触的来源，群像强调角色视角和聊天边界，桌游强调规则、变体和场景资料的区别。
- `world.summary`、`world.rules`、`canon` 和阶段策略用来记录世界设定。开启智能体搜索时，给聊天角色的自定义指令要从角色视角写。把幕后设定放在世界和搜索配置里。
- 对话先确定体验，再确定初始角色、聊天和开场。PresetAgent 可以在最后简短复述，等用户确认后完成创建。
