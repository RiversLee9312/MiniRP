# 世界与插件联动

## 为新对话设置开场

在预设页对 PresetAgent 说明你想要的开场。例如「新建对话时，请用旅馆老板的口吻欢迎刚抵达的玩家，并给一个行动线索」。PresetAgent 将引导保存到 `chat_agent.greeting_system_message`，设为空字符串即可关闭。该字段支持最多 16,000 字符。

配置开场后，Android 首页会显示「新建对话」按钮。创建后，ChatAgent 以隐藏的系统消息收到引导，再生成用户可见的欢迎语。旧对话不会补发开场。群像模式会在角色第一次进入其所属的聊天时使用引导，每个角色在同一 Room 内只开场一次。

## 让世界对行动有反应

角色可以触发插件技能，插件可以改变一项状态、发出事件，或请 EnvAgent 更新世界。EnvAgent 根据规则决定实际变化，再用系统消息告知受影响的角色。这样可以做值班交接、分组调查、资源调度、解谜、比赛复盘或共同维护一份任务清单。

建议把规则、状态、事件和界面分开。规则判断可以交给 EnvAgent 或插件的明确逻辑，状态放在插件自己的持久化设施里，状态卡只读这一份数据。Agent 要持续跟进某项状态时，可以订阅它的 DB 投影。完整示例见 [插件联动指南](../plugins/automation.md)。
