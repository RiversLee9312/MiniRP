# 世界与插件联动

## 为新对话设置开场

在预设页对 PresetAgent 说明你想要的开场。例如「新建对话时，请用旅馆老板的口吻欢迎刚抵达的玩家，并给一个行动线索」。PresetAgent 将引导保存到 `chat_agent.greeting_system_message`，设为空字符串即可关闭。该字段支持最多 16,000 字符。

配置开场后，Android 首页会显示「新建对话」按钮。创建后，ChatAgent 以隐藏的系统消息收到引导，再生成用户可见的欢迎语。群像模式让每个角色在同一 Room 内开场一次。角色可在已加入的多个群聊发言，也可以保持安静。重开 Room 时继续未完成的开场。

## 选择日期来源

在预设对话里告诉 PresetAgent 日期应该怎样变化。例如「跟随现实日期」，或「从 2032 年 2 月 29 日开始，每次结束一幕由插件推进一天」。PresetAgent 用 `configure_date` 保存日期来源及新 Room 的起始日期。

- **真实日期**随设备本地日历更新，是新预设的默认值。
- **由插件推进**时，每个 Room 保存自己的日期。插件通过 Harness 读写日期。关闭并重开 Room、分支、导出存档和再导入都会保留对应的时间线。旧预设的模拟日期会沿用。

需要手动改日期时，向 EnvAgent 指定日期。它通过 `world-state` Skill 的 `set_date` 工具设置当前 Room，格式为 `YYYY-MM-DD`。真实日期模式下，这次手动覆盖持续到下一个本地日期。委派搜索时，EnvAgent 和 SearchAgent 持有世界日期，ChatAgent 的 `{date}` 仍指现实日期。需要告诉角色世界日期时，可由插件 Skill 或 EnvAgent 通知。

## 让世界对行动有反应

角色可以触发插件技能，插件可以改变一项状态、发出事件，或请 EnvAgent 更新世界。EnvAgent 根据规则决定实际变化，再用系统消息告知受影响的角色。这样可以做值班交接、分组调查、资源调度、解谜、比赛复盘或共同维护一份任务清单。

建议把规则、状态、事件和界面分开。规则判断可以交给 EnvAgent 或插件的明确逻辑，状态放在插件自己的持久化设施里，状态卡只读这一份数据。智能体要持续跟进某项状态时，可以订阅它的 DB 投影。完整示例见 [插件联动指南](../plugins/automation.md)。
