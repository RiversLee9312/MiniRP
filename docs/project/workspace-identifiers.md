# 工作区标识与旧档迁移

核心为每个 Preset、Room 和 Chat 分配小写 UUID。普通对话的 Room 和 Chat 共用 UUID。群像每个 Room 有自己的 UUID，内部各条 Chat 在创建时也各自获得 UUID。插件通过 [Harness API](../plugins/harness.md) 或 Environment 获取实际 ID。名称和角色标签用于显示与搜索。

旧版工作区首次启动时，宿主在打开目录数据库、会话和插件前迁移。迁移计划保存在工作区的 `identity-migration.json`，完成后会标记。宿主移动会话文件与 SQLite 恢复文件，更新分支、预设会话、世界、作用域、卡片与订阅的已知引用，并从迁移后的记录重建列表索引。改写前的 JSON 保存在 `identity-backup/`。重新启动会继续未完成的计划。

宿主能识别并迁移它管理的存储位置和字段。插件业务数据如果自己保存了旧 ID，作者可以通过列表接口或当前事件上下文重新取得 UUID，再更新业务条目。遇到同名数据库冲突或无法确定归属时，宿主会保留原文件，归属由插件作者结合数据恢复。
